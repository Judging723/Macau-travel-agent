# 澳门无障碍旅游指南

来源：澳门特别行政区政府旅游局
来源网址：https://www.macaotourism.gov.mo/zh-hans/barrier-free-access-guide
资料抓取日期：2026-09-08

为配合澳门特区政府推动伤健共融和无障碍共融小区的建设工作，旅游局委托社服机构“澳门明爱”开展“澳门无障碍旅游设施调查”，评估本澳主要景点、口岸、会议展览场地、商场、酒店场所等设施的无障碍水平，并根据所得资料制作成本“无障碍旅游指南”。未来，旅游局将持续优化“无障碍旅游指南”，为有需要人士提供更广泛的参考资料。
## 代号和简称
- section：设施无障碍水平
- wheelChair：不限、适合、适合并符合本地通用设计标准
- carPark：有停车场
- valetParking：代客泊车
- visuallyImpaired：有为视觉受损人士而设之设施
- locked：设施对外开放
